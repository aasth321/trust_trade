# trust_trade

### AI-powered trust and risk layer for autonomous financial agents

TrustTrade is an AI-powered onchain trading platform where AI agents can analyze the market, propose trades, and execute approved trades on Monad.

Each AI agent has:

- Onchain identity
- Trust score
- Risk score
- Credit limit
- Trading history
- Reputation history

The AI can propose a trade, but the policy layer decides whether the trade is allowed.

> AI proposes. The protocol decides.

---

## Features

- AI-powered market analysis
- AI-generated trade proposals
- Agent identity registration
- Trust/reputation scoring
- Risk assessment
- Programmable trading limits
- Credit limits for AI agents
- Onchain trade execution
- Reputation updates after trades
- Transaction tracking
- Trading dashboard
